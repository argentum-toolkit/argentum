= Argentum ToolKit. Component Generator.

Component Generator creates components and their parts from templates.

== Supported generators

- db-infrastructure: DTO and Postgres repository for an entity
- fe-app: Dioxus front-end application skeleton

== How to install

=== Via cargo install

[source,shell]
----
cargo install argentum_component_generator_app
----

.From source codes
.Clone
[source,shell]
----
git clone git@gitlab.com:argentum-toolkit/argentum.git
----

.Install binary
[source,shell]
----
cargo install --path argentum_component_generator_app/
----

== How to use

[source,shell]
----
argentum_component_generator_app db-infrastructure --component-name user_account --entity-name User
argentum_component_generator_app fe-app --app-name my_app
----

Or via `cargo run` from the repository root (sources should be cloned):

[source,shell]
----
cargo run -p argentum_component_generator_app -- db-infrastructure --component-name user_account --entity-name User
----

`fe-app` accepts the global `--argentum-path` option to link local argentum crates:

[source,shell]
----
argentum_component_generator_app --argentum-path /path/to/argentum fe-app --app-name my_app
----

== Example

Generate a repository for a `Skill` entity in a `pro_pro` component:

[source,shell]
----
argentum_component_generator_app db-infrastructure --component-name pro_pro --entity-name Skill
----

Result:

- `pro_pro/infrastructure/src/db/dto/skill_dto.rs`
- `pro_pro/infrastructure/src/db/repository/skill_repository.rs`

The following lines are appended to `pro_pro/infrastructure/src/db/dto/mod.rs`:

[source,rust]
----
mod skill_dto;
pub(crate) use skill_dto::SkillDto;
----

The following lines are appended to `pro_pro/infrastructure/src/db/repository/mod.rs`:

[source,rust]
----
mod skill_repository;
pub use skill_repository::SkillRepository;
----
