== How to install

=== Via cargo install

[source,shell]
----
cargo install argentum_component_generator_app
----

.From source codes
.Clone
[source,shell]
----
git clone git@gitlab.com:argentum-toolkit/argentum.git

----

.Install binary
[source,shell]
----
cargo install --path argentum_component_generator_app/

----

== How to use

.Generate REST API server library
[source,shell]
----
argentum_component_generator_app pg-repository --component-name pro_pro --entity-name=Skill
#OR
cargo run -- pg-repository --component-name pro_pro --entity-name=Skill
----

Or you can generate via `cargo run` (sources should be cloned)
