= Quick start

== Requirements

* Docker
* Docker Compose
* Rust 1.89+
* Cargo

=== Optional for contributors

[source,shell]
----
cargo install cargo-edit
----

== Dependencies

[bash]
----
rustup update stable
----

== Setup project

* clone repository
* `devops/scripts/setup.sh`

== Start it on Docker

[bash]
----
docker compose up

# if you want to use local .env file
# docker compose --env-file .env --env-file .env.local up
----

== Also you can run the example of web application locally

[bash]
----
cd examples/api-app
cargo run --bin app
----

Now you can see API documentation and send requests via Swagger-UI. link:http://localhost:8083/[]

== Or run example of cli application:

[bash]
----
cd examples/cli-app
cargo run
----
